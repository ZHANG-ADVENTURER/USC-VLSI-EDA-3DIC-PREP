## Key Concepts

### Combinational Logic

Logic where the output depends only on the current input values. It does not require memory or a clock.

### Multiplexer

A circuit that selects one input from multiple inputs based on a select signal.

### Decoder

A circuit that converts a binary input into a one-hot output.

### Full Adder

A 1-bit arithmetic circuit that adds two input bits and a carry-in bit.

### Testbench

A simulation file that drives input values into a design module and observes the outputs.

### VCD File

A waveform dump file generated by simulation. It stores signal changes over time and can be opened in GTKWave.

### `.vvp` File

A compiled simulation output file generated by Icarus Verilog. It is executed by `vvp` to run the simulation.

### GTKWave

A waveform viewer used to check signal behavior over simulation time.
