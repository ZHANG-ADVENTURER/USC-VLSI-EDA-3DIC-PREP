# Sequence Detector FSM

## Overview

This project implements a Moore FSM sequence detector in Verilog.

The detector checks a serial input signal `bit_in` and asserts `detected = 1` when the input sequence `1011` is found.

This design uses overlapping detection, which means the last bit of one detected sequence can also be used as the first bit of the next sequence.

Example input:

1011011

This input contains two `1011` sequences:

- 1011
- 1011 with overlap

## Module Description

| Signal | Direction | Width | Description |
|---|---|---:|---|
| `clk` | input | 1 | Clock signal used to update the FSM state |
| `reset` | input | 1 | Synchronous reset signal that returns the FSM to `S_IDLE` |
| `bit_in` | input | 1 | Serial input bit checked by the sequence detector |
| `detected` | output | 1 | Becomes 1 when the sequence `1011` is detected |

## Testbench

The testbench verifies the FSM using a self-checking task called `check_detected`.

Each task call sends one input bit into the DUT, waits for one positive clock edge, and compares the actual `detected` output with the expected result.

Test sequence:

- Input sequence: `1011011`
- Target sequence: `1011`
- Detection type: overlapping detection

Test cases:

- Input `1`, expected `detected = 0`
- Input `10`, expected `detected = 0`
- Input `101`, expected `detected = 0`
- Input `1011`, expected `detected = 1`
- Input `10110`, expected `detected = 0`
- Input `101101`, expected `detected = 0`
- Input `1011011`, expected `detected = 1`

The simulation result shows that all test cases passed.
