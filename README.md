# USC VLSI / EDA / 3D IC Preparation Portfolio

This repository documents my summer preparation for VLSI, EDA, Physical Design, Static Timing Analysis, OpenROAD, and 2.5D / 3D IC design.

My background is in electrical engineering with hands-on experience in TSV-related advanced semiconductor packaging, including photolithography, DRIE, dielectric liner preparation, Ti/Cu barrier and seed-layer concepts, and copper electroplating preparation. This repository is designed to connect that fabrication background with VLSI design, manufacturability-aware EDA, and 3D IC physical design.
