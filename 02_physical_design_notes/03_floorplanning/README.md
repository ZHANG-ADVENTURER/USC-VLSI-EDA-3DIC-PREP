# Project Title

Floorplanning

# Overview

This project documents the fundamentals of ASIC floorplanning within the RTL-to-GDS physical design flow.

It covers die and core definition, aspect ratio, utilization, macro placement, macro orientation, channels, halos, blockages, I/O and pin planning, power-planning awareness, routability, congestion, and the impact of floorplanning on placement, routing, timing, and PPA.

# Files

* `notes/floorplanning.md`
  Detailed notes covering the main floorplanning concepts, physical-design tradeoffs, and their relationship to downstream implementation stages.

* `README.md`
  Project overview and file description.

# Module Description

This is a concept-based Physical Design study project rather than an RTL module implementation.

The project focuses on how a synthesized gate-level netlist is transformed into an initial physical organization before standard-cell placement.

Key topics include:

* Die Area and Core Area
* Core Margin
* Aspect Ratio
* Utilization
* Standard Cells and Macros
* Macro Placement and Orientation
* Channels, Halos, and Blockages
* I/O and Pin Planning
* Power Distribution Awareness
* Routability and Congestion
* Floorplanning Impact on Timing and PPA
